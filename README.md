### Hybrid Fake News Detector
> *High-accuracy ensemble ML pipeline with real-time credibility analysis and web verification.*

**Type:** AI / Data Intelligence &nbsp;|&nbsp; **Status:** ✅ Complete &nbsp;|&nbsp; **Accuracy:** `96.46%`

8,000-feature TF-IDF pipeline with ensemble voting across multiple ML models. Integrates Gemini AI for contextual credibility analysis and real-time web source verification. Production-ready API surface via FastAPI with a Streamlit-powered interface.

```
Stack: FastAPI · Streamlit · Scikit-Learn · TF-IDF · Gemini AI · Ensemble Voting
```
